# NETWORKWALKS-WK3-Password-Cracking-Lab
Password Cracking with John the Ripper(JTR), Johnny and NetworkWalks tools

**Author:** Aravind P (Networkwalks Intern)

**Program:** Cybersecurity Internship Program at NetworkWalks, Week 03
## Project Overview:
This project focuses on understanding password security and password recovery by two practical modules.

The exercises involve using John the Ripper (JTR) and its graphical interface, Johnny, on Windows, as well as NetworkWalks' online Hash Calculator and Password Cracker tools.

The objective was to understand how password hashes are extracted and how password cracking tools can be used in authorized security testing to demonstrate password strength 
and weaknesses.
## Modules Completed:
WK3-PM1: Password Cracking with John the Ripper (JTR) and Johnny.

WK3-PM2: Password Cracking with NetworkWalks Tools.

## Tasks Completed:
###1. WK3-PM1 — Password Cracking with JTR

Objective: Recover the passwords of the provided protected PDF files using John the Ripper and Johnny on Windows.

Activities performed:

1. Downloaded and configured Johnny on my Windows PC.

2. Obtained the provided password-protected PDF files.

3. Used the File Conversion Tool to extract password hashes.

4. Saved the extracted hash in a text file named hash1.txt.

5. Opened the hash file using Johnny.

6. Started a new password recovery attack.

7. Successfully recovered the password of the first PDF.

Result: Successfully recovered the passwords of the provided PDF file.

###2. WK3-PM2 — Password Cracking with NetworkWalks Tools

Objective: Use NetworkWalks online tools to extract and recover the password of a protected PDF file.

Activities performed:

1. Opened NetworkWalks Hash Calculator.

2. Uploaded the provided password-protected PDF file.

3. Extracted and copied its password hash.

4. Opened NetworkWalks Password Cracker.

5. Submitted the extracted hash.

6. Observed the password cracking process.

Result: The Password Cracker processed the available wordlists and successfully recovered the correct password.

## What I learned and Observations:

With these two modules, I gained hands on experience with password recovery and password security testing.

I learned how to extract password hashes from protected PDF files, load them into Johnny tool and perform password recovery.

I learned NetworkWalks' online Hash Calculator and Password Cracker to get a understanding of how wordlists are used during password cracking attempts.

This exercise helped me understand why strong, unique passwords are important and how security assessments can help identify weak passwords before they become a security risk.

Password protected files can contain hashes that can be extracted for authorized security testing.

Password recovery tools can test password strength using different wordlists.

Weak or commonly used passwords may be recovered more easily.

John the Ripper and Johnny tools provide practical ways to understand password security.

Online password cracking tools can demonstrate the password recovery process without requiring local installation.
