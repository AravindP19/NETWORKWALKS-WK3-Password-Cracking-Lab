# NETWORKWALKS-WK3-Password-Cracking-Lab
Password Cracking with John the Ripper(JTR), Johnny and NetworkWalks tools

**Author:** Aravind P (Networkwalks Intern)

**Program:** Cybersecurity Internship Program at NetworkWalks, Week 03
## Project Overview:
This project focuses on understanding password security and password recovery by two practical modules.

The exercises involve using John the Ripper (JTR) and its graphical interface, Johnny, on Windows, as well as NetworkWalks' online Hash Calculator and Password Cracker tools.

The objective was to understand how password hashes are extracted and how password cracking tools can be used in authorized security testing to demonstrate password strength 
and weaknesses.
## Modules Completed:
WK3-PM1: Password Cracking with John the Ripper (JTR) and Johnny.

WK3-PM2: Password Cracking with NetworkWalks Tools.
## Tools Used:
|              Tool             |                       Purpose                       | 
|:-----------------------------:|:---------------------------------------------------:|
| John the Ripper (JTR)         | Password security testing and password recovery     | 
| Johnny                        | Graphical interface for John the Ripper             | 
| NetworkWalks Hash Calculator  | Extracting password hashes from protected PDF files | 
| NetworkWalks Password Cracker | Testing password hashes against available wordlists | 
| Windows PC                    | Environment used for the JTR practical exercise     |
